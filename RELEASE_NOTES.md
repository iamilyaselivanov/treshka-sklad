# ТРЁШКА СКЛАД — заметки к версии 1.6

## Миграции базы данных

- Миграция `0013_thin_radioactive_man.sql` добавляет точный индекс шапок актов
  инвентаризации и удаляет больше не используемую таблицу
  `inventory_act_counters`.
- Удаление таблицы необратимо. После применения `0013` откат приложения на
  версию, которая ожидает `inventory_act_counters`, не поддерживается.
- Перед применением миграции на рабочей базе необходимо сохранить резервную
  копию D1. Возврат выполняется восстановлением этой копии либо следующей
  прямой миграцией, а не запуском старого кода поверх новой схемы.
